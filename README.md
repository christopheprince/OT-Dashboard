# OT-Dashboard

OT Dashboard — Industrial Network Security & Analytics

A standalone, browser-based tool for OT/ICS network traffic analysis.

No installation. No backend. No internet connection required.

Features : topology, host inventory, flow analysis, anomaly detection, OT protocol deep parsing (Modbus, EtherNet/IP, S7, PROFINET, DNP3), threat intelligence, PDF report.

Usage : ouvre le fichier HTML dans Chrome, charge un .pcap ou .pcapng, tout tourne localement dans le navigateur.
